# ResiliNet AI Module

This module handles AI and Computer Vision functionality for ResiliNet.

## Modules

### CV
OpenCV-based image processing.

### Detection
YOLO-based road obstruction detection.

### Preprocessing
Image resizing and preprocessing.

### GeoTrust
GPS-to-road matching and confidence scoring.

## Planned AI Pipeline

Field Image
→ Preprocessing
→ YOLO Detection
→ Obstruction Detection
→ Confidence Score
→ GPS Road Matching
→ GeoTrust Score
